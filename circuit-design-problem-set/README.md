# Circuit Design Problem Set (1과제 회로설계 연습)

2019년 전국기능경기대회 준비 과정에서 개인적으로 모아 연습했던 회로설계(1과제) 문제·정답 세트입니다.
문제지 형식(직종/과제명/경기시간/진리표/재료목록)과 정답 회로도로 구성되어 있으며, 실제 대회에 출제된 공식 문제가 아니라 **연습용으로 사용한 개인 문제은행**입니다.

각 폴더는 문제(`problem.md`)와 정답(`answer.md`)으로 구성되며, 원본 HWP 파일에 포함되어 있던 회로도 이미지를 그대로 추출해 첨부했습니다.

## 연습 문제 목록

1. [2음 경보기](./01-2eum-alarm) — NAND/아날로그 스위치(4066) 기반 2음 경보기

3. [전자 사이크로](./03-electronic-cycro)
4. [횡단보도 제어기](./04-crosswalk-controller) — XOR/OR 게이트 기반 신호 제어 로직
5. [예약된 숫자 표시기](./05-reserved-number-display)
6. [10진 계수기](./06-decimal-counter)
7. [10진 설정 경보기](./07-decimal-set-alarm) — NE555 발진 + 정전압 회로(7905)
